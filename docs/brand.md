# Brand

qat is the product. **Powered by AcademiaQA** is the signature, never the hero.

## Domains (as of 2026-09-09)

| Domain | Status | Action |
| --- | --- | --- |
| **qat.dev** | Taken. Cloudflare Registrar, created 2026-04-05, Access login wall. | Do not buy. Do not wait. |
| **qat.sh** | Not registered. | Buy this. Public liner: `https://qat.sh/install.sh`. |
| **getqat.dev** | Not registered. | Buy this as the `.dev` liner if you want a `.dev` URL. |

Until `qat.sh` resolves, the working liner is GitHub:

```bash
curl -fsSL https://raw.githubusercontent.com/Simonethg/qat/main/install.sh | sh
```

`install.sh` tries, in order: `QAT_MANIFEST_URL`, `https://qat.sh/latest.json`, `https://getqat.dev/latest.json`, then GitHub Releases / raw `latest.json`.

GitHub: [github.com/Simonethg/qat](https://github.com/Simonethg/qat). Hiring identity, not an AcademiaQA org.
