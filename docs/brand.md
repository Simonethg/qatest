# Brand

qatest is the product. **Powered by AcademiaQA** is the signature, never the hero.

## Domains

| Domain | Status | Action |
| --- | --- | --- |
| **qatest.dev** | Taken. | Do not wait on it. |
| **qatest.sh** | Available. | Buy this. Public liner: `https://qatest.sh/install.sh`. |

Until `qatest.sh` resolves, the working liner is GitHub:

```bash
curl -fsSL https://raw.githubusercontent.com/Simonethg/qatest/main/install.sh | sh
```

`install.sh` tries, in order: `QATEST_MANIFEST_URL`, `https://qatest.sh/latest.json`, then GitHub Releases / raw `latest.json`.

GitHub: [github.com/Simonethg/qatest](https://github.com/Simonethg/qatest).
